# CUTLINE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build CUTLINE as a working full-stack application that turns trip media into a 20–25 second vertical trailer, theatrical poster, and cast cards, with live agent progress and an offline sample experience.

**Architecture:** A FastAPI backend owns uploaded workspaces, media processing, LangGraph orchestration, generated assets, and buffered SSE events. A Next.js frontend owns the three-view workflow and consumes typed REST/SSE contracts. Gemini and edge-tts are replaceable providers; deterministic sample providers and pre-baked outputs keep the demo independent of API keys and external services.

**Tech Stack:** Python 3.12, FastAPI, Pydantic v2, LangGraph, google-genai, OpenCV, Pillow, imagehash, rembg, edge-tts, ffmpeg-python, pytest; Next.js 16, React 19, TypeScript, Tailwind CSS 4, Motion, Phosphor Icons, Vitest.

**Spec:** `design-system/cutline/MASTER.md` plus the user's five-phase CUTLINE requirements.

## Global Constraints

- Trailer output is H.264 MP4, 1080×1920, 9:16, with audio and a verified duration of 20–25 seconds.
- Poster output is 1080×1920 PNG with title, tagline, “98% Certified Chaotic” badge, and billing-block credits.
- Real uploads accept 10–25 photos/short videos; the bundled sample contains 8 assets and bypasses that minimum.
- Surviving perception images are deduplicated, blur-filtered, and resized to a 768px maximum dimension before Gemini calls.
- Gemini model starts with `gemini-3.5-flash-lite` (selected after live availability probes); structured responses use the backend Pydantic schemas.
- No `GEMINI_API_KEY` is required for **Load Sample Chaos Trip**; sample mode never calls Gemini or edge-tts.
- UI uses the exact cinema tokens and three-view architecture in the design-system Master file.
- All motion respects reduced motion; gesture interactions have keyboard/button alternatives; touch targets are at least 44×44px.
- No generic AI SaaS gradients, blobs, marketing hero, nested card borders, or placeholder copy.
- Do not commit or initialize git unless the user explicitly asks.

## Review Focus

- Oversized, mixed, corrupt, or unsupported uploads must produce bounded field-level errors rather than worker crashes; Task 1 and Task 5 tests pin validation and API error recovery.
- SSE disconnects and page reloads must not restart rendering or lose completed events; Task 5 tests pin buffered replay and idempotent project execution.
- Missing music, voice synthesis failure, or too few surviving assets must use explicit fallback behavior; Tasks 2, 4, and 6 tests pin these paths.
- Long titles, cast names, and voiceover lines must fit generated media and responsive UI without clipping; Tasks 4 and 7 tests pin wrapping/ellipsis and viewport overflow.
- Browser autoplay/Web Audio restrictions must not block native video controls or the timeline; Task 7 tests pin graceful analyser fallback.
